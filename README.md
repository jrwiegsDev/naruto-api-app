# Naruto Character Encyclopedia

Welcome to the Naruto Character Encyclopedia, a dynamic web application built with React that allows users to explore the vast world of Naruto characters. This application fetches data from the [Dattebayo API](https://dattebayo-api.onrender.com/) and provides a clean, responsive interface for searching, filtering, and viewing character details.

## Features

- **Dynamic Search:** Instantly search for characters by name.
- **Multi-Filter System:** Filter characters by their village, ninja rank, gender, chakra nature, kekkei genkai, and even birth month.
- **Client-Side Filtering:** A fast and responsive filtering engine that processes a large dataset directly in the browser.
- **Interactive UI:**
    - A three-column layout for easy navigation.
    - Clickable character gallery to view detailed information.
    - "Clear" buttons to easily reset filters and selections.
    - A "Part I / Part II" image switcher for characters with multiple appearances.
- **Responsive Design:** The layout is built with modern CSS (Grid and Flexbox) to be usable on various screen sizes.

## Technologies Used

- **React:** For building the user interface with components and managing state.
- **Vite:** As the fast and modern build tool for the development environment.
- **JavaScript (ES6+):** For all application logic, including API calls and filtering.
- **CSS3:** For all custom styling, including a dark mode theme and responsive layouts using Grid and Flexbox.
- **Git & GitHub:** For version control.

## Setup

To run this project locally:

1.  Clone the repository:
    `git clone <your-repository-url>`
2.  Navigate to the project directory:
    `cd naruto-api-app`
3.  Install dependencies:
    `npm install`
4.  Start the development server:
    `npm run dev`
